# p3_sirena_boarding_passes

Максим Швырёв. Источники: выгрузка системы бронирования Sirena (`Sirena-export-fixed.tab`, 56 МБ) и посадочные талоны (`YourBoardingPassDotAero.zip`, 366 файлов XLSX).

Посадочные талоны лежат по одному Excel-файлу на день, в каждом тысячи листов. Лист - это не таблица, а макет талона, поля разбросаны по ячейкам, поэтому они читаются по координатам. Дата рейса сверяется с названием файла. Sirena - текст с колонками фиксированной ширины, ФИО на кириллице, поля читаются по позициям символов, номера карт достаются из поля PaxAdditionalInfo.

## Что получается

| Файл | Одна строка | Строк |
|---|---|---|
| `output/sirena.csv` | бронь в Sirena | 155 757 |
| `output/boarding_passes.csv` | посадочный талон | 615 771 |
| `intermediate/sirena_errors.csv` | строка Sirena, которую не удалось разобрать | 0 |
| `intermediate/boarding_passes_errors.csv` | лист XLSX, который не удалось разобрать | 0 |

Обе таблицы из `output/` забирает `integration/src/merge_all.py`.

## Что нашлось

- В Sirena нет битых кодов аэропортов, поэтому при спорах о маршруте она считается самым надёжным источником.
- В посадочных талонах 22 787 строк с битым аэропортом. Дат рождения и документов в талонах нет, карта лояльности указана только у 21%.
