# reports

Отчёты, которые пересоздаются скриптами: `REPORT.md` (`build_report.py`) - сводка по признакам и категориям, рейтинг и проверка известных случаев; `ALL_FEATURES_SUMMARY.md` (`build_all_features.py`) - статистика по всем людям с признаками; `CAT6_SUMMARY.md` (`CAT6_connections.py`) - связи с людьми из списка.
