# output

Результаты признаков.

| Файл | Что в нём |
|---|---|
| `<код>_results.csv` | люди, у которых сработал признак. Одна строка на `person_id`, колонки `<код>_flag`, `<код>_count` (сколько случаев) и подробности |
| `category_<X>_results.csv` | признаки категории вместе: `<X>_flags_count` - сколько разных признаков сработало, `<X>_total_occurrences`, `<X>_triggered_features` |
| `all_features_results.csv` | все люди с признаками: число сильных, средних и слабых признаков, категории, подробности, другие профили того же человека |
| `report_ranking.csv` | рейтинг: число сильных признаков, категорий, признаков |
| `CAT6_results.csv`, `CAT6_pairs.csv` | связи с людьми из списка: по людям и по парам |
| `D1_pairs.csv` | пары постоянных попутчиков с разными именами |
| `D1_same_person_candidates.csv` | пары профилей одного человека (двойники), их используют другие признаки |
| `D1_same_person_check.*` | проверка этих пар |
| `D1_two_passports_*` | проверка пар с внутренним и заграничным паспортом |
| `D2_pairs.csv` | пары с общей бронью (пусто) |

Пустой файл признака значит, что признак не сработал ни у кого.
