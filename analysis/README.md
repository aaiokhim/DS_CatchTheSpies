# analysis

Третий этап: признаки подозрительного поведения. Один скрипт считает один признак и пишет результат в `output/<код>_results.csv`. Признаки разбиты на пять категорий, A-E, а отдельный скрипт проверяет связи между людьми (категория 6). Что значит каждый признак и как он считается - в `docs/SPY_FEATURES.md`.

## Скрипты

| Скрипты | Что считают |
|---|---|
| `A1` … `A7` | личность и идентификаторы: общие документы, карты, аккаунты, несколько паспортов |
| `B1` … `B5` | бронь, посадка и мили: разрывы между ними, общие билеты, нет даты рождения |
| `C1`, `C2`, `C3`, `C5`, `C6` | время и география: невозможные маршруты, частота, короткие поездки, редкие направления |
| `D1`, `D2` | совместные поездки и общие брони |
| `E1`, `E2` | карты лояльности и перекос источников |
| `D1_same_person_check.py`, `D1_two_passports_check.py` | проверки пар, которые оказались одним человеком |
| `build_category_A.py` … `build_category_E.py` | сводят признаки категории в одну таблицу |
| `build_report.py` | общий отчёт `reports/REPORT.md` и рейтинг `output/report_ranking.csv` |
| `build_all_features.py` | все люди с признаками в одной таблице и статистика по ним |
| `CAT6_connections.py` | связи всех людей с людьми из списка A-E |
| `common.py` | общие функции, сам ничего не считает |

Порядок запуска: сначала `D1_cotravelers.py`, потом остальные признаки в любом порядке, потом `build_category_*`, потом `build_report.py`, `build_all_features.py` и `CAT6_connections.py`. Всё сразу запускает `scripts/run_all.sh`.

C3 и часть C1 используют расписание участника 1 (`participants/p1_timetable/output/timetable_unique.csv`). Без него C3 не считается, а C1 берёт время прилёта только из данных.

## Двойники

Склейка разделила 11 255 человек на два профиля. `D1_cotravelers.py` находит такие пары: одинаковое имя и не меньше трёх общих перелётов. Пары записываются в `output/D1_same_person_candidates.csv`. Если у обоих профилей известны даты рождения и они разные или разный пол, пара не считается одним человеком. Признаки A2, B, C, E2 и категория 6 считают человека вместе с его двойником, сами таблицы склейки при этом не меняются.

Хотя бы один признак есть у 35 468 профилей, сильный - у 19 (5 человек и 10 отдельных записей с общей картой). Связь с людьми из списка нашлась у 940 человек, 903 из них сами без признаков, но 897 связаны только с людьми со слабыми признаками.
