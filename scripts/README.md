# scripts

| Скрипт | Что делает |
|---|---|
| `run_all.sh` | запускает проект по порядку, начиная со склейки. С `--from-raw` начинает с разбора исходников |
| `prepare_merged.py` | кладёт готовые общие таблицы в `integration/merged/` и режет `flights_all` на файлы по источникам |
| `check_repo.py` | перед `git push` проверяет, что нет файлов больше 50 МБ и в каждой папке есть README |
