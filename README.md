# Catch the Spies

Командный проект по анализу данных о перелётах. Данные о пассажирах приходят из семи разных источников: бронирования, посадочные талоны, форум часто летающих пассажиров, программы лояльности, расписание. Задача - собрать их вместе, понять, какие записи относятся к одному человеку, и найти пассажиров с подозрительным поведением.

Команда: Станислав Лисенков, Анна Иохим, Максим Швырёв, Анастасия Зотова (группа Б24-513).

## Как устроен проект

Работа шла в три этапа, каждому соответствует своя папка. Каждый этап только читает результат предыдущего и ничего не меняет в исходных данных.

```
data/raw/            исходные файлы (в репозиторий не входят)
participants/        этап 1: каждый участник разбирает и чистит свои источники
integration/         этап 2: все источники сводятся в один формат и склеиваются в людей и перелёты
analysis/            этап 3: признаки подозрительного поведения, отчёты
docs/                описание признаков
scripts/             запуск всего проекта и служебные скрипты
paths.py             все пути проекта, скрипты берут папки отсюда
```

Кто за что отвечал на первом этапе:

| Папка | Участник | Источники |
|---|---|---|
| `participants/p1_timetable` | Станислав | расписание SkyTeam (PDF) |
| `participants/p2_forum_boarding` | Анна | профили форума (JSON), BoardingData (CSV) |
| `participants/p3_sirena_boarding_passes` | Максим | выгрузка Sirena (TAB), посадочные талоны (366 XLSX) |
| `participants/p4_pointz_skyteam` | Анастасия | Pointz (XML), SkyTeam (YAML) |

Сведение, склейку и признаки делали вместе, код лежит в `integration/` и `analysis/`.

## Какие данные есть в репозитории

Исходных файлов здесь нет, они весят около 1,5 ГБ. Список того, что должно лежать в `data/raw/`, есть в `data/raw/README.md`.

Из данных в репозитории лежат две общие таблицы, в которые сведены все источники:

- `integration/merged/passengers_all.parquet` - 1 059 924 записи о пассажирах;
- `integration/merged/flights_all/` - 4 358 805 записей о перелётах, по файлу на источник (одним файлом таблица больше лимита GitHub).

Из них воспроизводится всё остальное: склейка, признаки и отчёты. Ещё в репозитории есть примеры таблиц каждого участника (по 20-100 строк в папках `samples/`), отчёты о качестве и все итоговые результаты в `analysis/output/` и `analysis/reports/`.

## Запуск

Нужен Python 3.10 или новее.

```
pip3 install -r requirements.txt
```

Все команды запускаются из корня репозитория. Проще всего запустить всё подряд:

```
bash scripts/run_all.sh
```

Скрипт начинает со склейки, потому что общие таблицы уже лежат в `integration/merged/`. На полных данных это занимает несколько десятков минут.

Если нужно пересобрать проект с самого начала, нужны исходники в `data/raw/` и таблицы участников в `participants/*/output/`. Тогда `bash scripts/run_all.sh --from-raw`.

Порядок по шагам:

| Шаг | Команда | Что получается |
|---|---|---|
| 1 | парсеры участников (`participants/*/src/`) | `participants/*/output/` |
| 2 | `python3 participants/p2_forum_boarding/src/pipeline.py` | таблицы форума и BoardingData |
| 3 | `python3 integration/src/merge_all.py --no-csv` | `integration/merged/` |
| 4 | `python3 integration/src/resolve_entities.py --no-csv` | `integration/resolved/`: люди и перелёты |
| 5 | `python3 integration/src/name_check.py`, `name_candidates.py` | проверка склейки |
| 6 | `python3 analysis/D1_cotravelers.py` | попутчики и файл двойников, он нужен остальным признакам |
| 7 | остальные `analysis/A*.py … E*.py`, затем `build_category_*.py` | результаты признаков |
| 8 | `build_report.py`, `build_all_features.py`, `CAT6_connections.py` | отчёты и связи |

Шаги 1-3 без исходных данных не запустятся. Шаги 4-8 работают на том, что уже есть в репозитории.

## Основные результаты

- После склейки получилось 595 649 профилей пассажиров (`person_id`) и 2 417 794 перелёта. 11 255 пар профилей оказались одним и тем же человеком, разделённым на две части, так что людей примерно 584 тысячи.
- Ошибок склейки не нашли: внутри одного профиля нет разных имён, дат рождения и пола, а признак невозможных маршрутов не сработал ни разу.
- Хотя бы один признак сработал у 35 468 профилей, в основном за счёт слабых признаков. Сильные признаки нашлись у 19 профилей. За ними стоят 5 человек: Гордей Глебов и Рамиль Буров (один паспорт на двоих), Амалия Кудрявцева (два внутренних паспорта с разным отчеством), Роман Масленников и Олеся Головина (одна карта лояльности). Ещё 10 профилей - отдельные записи с той же картой. Отдельно Юлия Коршунова и Станислав Кондратов делят один аккаунт Pointz.
- Связи с людьми из списка нашлись у 940 человек, но 897 из них связаны только с людьми со слабыми признаками.

Описание всех признаков и того, как они считаются, - в `docs/SPY_FEATURES.md`. Полные цифры - в `analysis/reports/`.
