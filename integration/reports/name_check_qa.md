## Как читать

- `resolved/name_mismatches.csv` - каждый несовпавший вариант имени: какое основное имя, какое отличающееся, из каких источников, какие слова различаются.
- `resolved/name_check_persons.csv` - один человек = одна строка, худшая категория.
- Найти, через какой ключ склеились записи: `resolved/record_links` (person_id) + `merged/passengers_all` / `flights_all` (карта, документ, билет, PNR этих записей).
- `different_name` и `one_word_differs` - кандидаты на проверку: либо ошибка склейки, либо один человек под разными именами (что может быть признаком для поиска шпионов).
