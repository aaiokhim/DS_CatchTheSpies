# integration

Второй этап: таблицы всех участников сводятся в один формат, а потом записи склеиваются в людей и перелёты.

| Скрипт | Что делает | Пишет |
|---|---|---|
| `src/merge_all.py` | сводит все источники в две таблицы одного формата | `merged/`, `reports/merge_qa.md` |
| `src/resolve_entities.py` | строгая склейка людей и перелётов | `resolved/`, `reports/resolve_qa.md` |
| `src/name_check.py` | проверяет, нет ли в одном профиле разных имён | `resolved/name_mismatches*`, `reports/name_check_qa.md` |
| `src/name_candidates.py` | предлагает пары по именам для записей, которые не склеились | `resolved/name_link_candidates*`, `reports/name_candidates_qa.md` |

`merge_all.py` без исходных данных не запустится, его результат уже лежит в `merged/`. Остальные три скрипта запускаются в этом порядке.

## Сведение

Все источники приведены к одному формату: пустые значения (`N/A`, `Not presented` и т.п.) стали пропусками, даты в виде `YYYY-MM-DD`, время `HH:MM`, рейс `SU1180`, документ без пробелов, карта `FB 139888197`, аэропорт из трёх заглавных букв (исходное значение в колонке `*_raw`). Строки не удалялись, дубликаты не убирались, имена не менялись: кириллица Sirena осталась кириллицей.

Пять кодов аэропортов (rea, ova, nia, ngo, nds) - обрезанные названия стран. Они помечены флагом `is_suspicious_airport`, но не исправлены.

## Склейка

Записи считаются одним человеком, если у них совпадает хотя бы один сильный ключ: карта лояльности, документ, номер билета, PNR вместе с рейсом и датой или принадлежность перелёта профилю. Связь работает по цепочке, через граф. Имена в склейке не участвуют: тёзок слишком много (58 тысяч разных ФИО на 101 тысячу документов).

Ключ, который встречается у явно разных людей, из склейки исключается. Таких два: карта FB 139888197 и документ 8248013778 (`resolved/conflicted_keys.csv`).

Перелёт - это человек, номер рейса и дата. Аэропорт перелёта берётся из самого надёжного источника, где он не битый: Sirena, затем посадочные талоны, BoardingData, Pointz, форум и в последнюю очередь SkyTeam.

## Результат

- 4 492 054 записи, из них 595 649 профилей и 2 417 794 перелёта. 1 421 863 перелёта подтверждены двумя и более источниками.
- Внутри профилей нет разных имён и дат рождения.
- Около 25,6 тысячи анонимных профилей форума получили имя через карты.
- 431 895 посадочных талонов остались одиночками: у них нет ни документа, ни карты, присоединить их не к кому.
- Часть людей склейка разделила на два профиля: в одном брони и посадки (связаны документом), в другом мили (связаны картой). Таких пар 11 255. Склейку мы не переделывали, эти пары учитываются внутри признаков, см. `analysis/README.md`.
