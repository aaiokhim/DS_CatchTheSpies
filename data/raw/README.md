# data/raw

Сюда кладутся исходные файлы в том виде, в каком их выдали. В репозиторий они не входят: вместе это около 1,5 ГБ, а GitHub не принимает файлы больше 100 МБ. Папка нужна только для полного перезапуска с нуля.

| Файл | Размер | Кто обрабатывает |
|---|---|---|
| `Skyteam_Timetable.pdf` | 312 МБ | Станислав (p1) |
| `FrequentFlyerForum-Profiles.json` | 568 МБ | Анна (p2) |
| `BoardingData.csv` | 19 МБ | Анна (p2), его же напрямую читает `integration/src/merge_all.py` |
| `Sirena-export-fixed.tab` | 56 МБ | Максим (p3) |
| `YourBoardingPassDotAero.zip` (366 XLSX) | | Максим (p3) |
| `PointzAggregator.xml` | 146 МБ | Анастасия (p4) |
| `SkyTeam-Exchange.yaml` | 164 МБ | Анастасия (p4) |

Файлы лежат прямо в этой папке, без подпапок, с исходными именами. Пассажирские данные покрывают 2017 год и 1 января 2018 года, расписание - ноябрь 2018 - январь 2019.
